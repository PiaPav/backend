# Общие инструкции проекта

Ты работаешь с этим репозиторием автономно.

## Общие правила

- Перед внесением изменений изучай существующую архитектуру и реализацию.

- Не перерабатывай работающие компоненты без конкретной необходимости.

- Сохраняй обратную совместимость, если задача явно не требует её нарушения.

- Следуй существующему стилю кода и соглашениям проекта.

- Не изменяй файлы за пределами текущего репозитория.

- Не читай и не изменяй секреты, если это не требуется задачей.

- Не выполняй push в удалённые репозитории.

- Не удаляй Git-ветки.

- Не переписывай историю Git.

- Не используй функционал Git в принципе;

- Не выполняй несвязанный с задачей рефакторинг.

## Порядок разработки

Для каждой существенной задачи:

1. Проанализируй репозиторий и текущую реализацию.

2. Определи затрагиваемые компоненты.

3. Сформируй план реализации.

4. При необходимости используй специализированных субагентов.

5. Реализуй изменение.

6. Добавь или обнови тесты.

7. Запусти релевантные тесты.

8. Проверь итоговый diff.

9. Проведи независимое ревью.

10. Исправь обнаруженные существенные проблемы.

11. Повторно запусти необходимые проверки.

Задача не считается завершённой, пока реализация и проверка не закончены.

Не останавливайся на этапе предложения решения или написания плана, если пользователь запросил реализацию.
