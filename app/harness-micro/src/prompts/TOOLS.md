## Нативные вызовы инструментов

Вызывай инструменты только через native tool calls провайдера. Имя и JSON-аргументы должны соответствовать переданным
JSON Schema. Не печатай вызов как команду в `content`. Несколько вызовов в одном ответе исполняются последовательно.
Описание ниже поясняет семантику; угловые скобки показывают значения полей, а не текстовый синтаксис вызова.

### Получить содержимое указанного файла

```
GET-CONTENT <FILEPATH>
```

где:

- `FILEPATH` - путь к файлу в соответствии с путем, указанным в графе
  (части пути через "/" и название файла с расширением)

### Получить диапазон строк исходного кода

```
GET-CODE-RANGE <FILEPATH> <START-LINE> <END-LINE>
```

где `FILEPATH` — путь индексированного Python-файла, а `START-LINE` и `END-LINE` — номера первой и последней
физической строки (1-based, обе границы включительны). Инструмент сохраняет пробелы и может вернуть только начальный
префикс диапазона при превышении лимита; это отражается в `completeness`.

### Получить структуру из файла

```
GET-STRUCTURE <FILEPATH> <STRUCTURE-TYPE> <STRUCTURE-PATH>
```

где:

- `FILEPATH` - путь к файлу в соответствии с путем, указанным в графе
  (части пути через "/" и название файла с расширением)
- `STRUCTURE-TYPE` - тип структуры (`CLASS`, `FUNCTION`, `METHOD`, `CONSTANT`)
- `STRUCTURE-PATH` - путь структуры.
  При разных типах:
  `CLASS` - название класса (пример: `AccountData`),
  `FUNCTION` - название функции (пример: `load_config`),
  `METHOD` - название класса и метода (пример: `ProjectService.delete_project`),
  `CONSTANT` - название константы (пример: `ERROR_SCHEMA`)

### Получить целый профиль графа

```
GET-GRAPH <PROFILE-ID>
```

`PROFILE-ID` — точный непустой ключ каталогизированного графового профиля, без
trim, алиасов и автовыбора. Возвращается целый JSON-объект; частичная выдача
запрещена, а превышение общего UTF-8 лимита даёт `extraction_limit_exceeded`.

### Найти узлы графа

```
FIND-GRAPH-NODES <QUERY> [KIND] [PATH] [LIMIT]
```

Поиск выполняется в `canonical.full`: `QUERY` — непустая casefold-подстрока
`qualified_name` без trim и Unicode-нормализации. `KIND` и `PATH` — точные
AND-фильтры (`PATH` — регистрозависимый относительный POSIX-путь). Совпадения не
дедуплицируются, сортируются по имени и ID, затем ограничиваются `LIMIT` (по
умолчанию 20, максимум 100); `completeness.total` содержит число до ограничения.

### Получить узел графа

```
GET-GRAPH-NODE <NODE-ID>
```

`NODE-ID` непустой и сравнивается точно, без trim, casefold или нормализации.
Возвращается полный объект узла `canonical.full`; частичная выдача запрещена.
Превышение общего размера ответа даёт `extraction_limit_exceeded`.

### Получить целый профиль метрик

```
GET-METRICS <PROFILE-ID>
```

`PROFILE-ID` — точный непустой ключ каталогизированного профиля метрик, без
trim, алиасов и автовыбора. Возвращается целый исходный JSON-объект; при
превышении общего UTF-8 лимита частичный результат не выдаётся.

### Получить элемент профиля метрик

```
GET-METRICS-ITEM <PROFILE-ID> <METRIC-PATH>
```

`PROFILE-ID` — точный непустой ключ профиля. `METRIC-PATH` — RFC 6901 JSON
Pointer относительно фактического корня артефакта (пустая строка означает
корень; fragment-форма `#` не поддерживается). Данные, включая структуры
`$columns`/`$rows`, возвращаются без преобразования: их DTO-контракт пока
неоднозначен.

### Получить ограниченный подграф

```
GET-GRAPH-SUBGRAPH <PROFILE-ID> <NODE-ID> <DEPTH> [RELATION-TYPE] [DIRECTION]
```

Профиль выбирается точно. `DIRECTION` принимает `incoming`, `outgoing` или
`both` и по умолчанию равен `both`. Инструмент выполняет ограниченный BFS после
фильтрации вида связи и возвращает узлы с расстояниями и induced набор рёбер.
При `DEPTH=0` возвращаются seed и его self-loops. Ограничение и неполнота явно
отражаются в `counts` и `completeness`.

### Получить принадлежащие узлу ссылки

```
GET-GRAPH-REFERENCES <OWNER-NODE-ID> [REFERENCE-TYPE] [STATUS]
```

Инструмент читает `canonical.full`. `REFERENCE-TYPE`: `call`, `import`, `type`.
`STATUS`: `exact`, `ambiguous`, `external`, `dynamic`, `unresolved`. Фильтры
соединяются через AND; возвращаются только непосредственные occurrences
владельца, без превращения кандидатов неоднозначной ссылки в точные связи.
