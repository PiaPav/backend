## Команды

Запрос инструмента — полный ответ строго из двух строк: первая строка `tool`, вторая — одна из команд ниже с
подставленными аргументами. Не добавляй вступление, объяснение, пустые строки, Markdown-ограждения или текст после
команды. После запроса дождись ответа инструмента.

Ограждения в этом описании служат только для показа синтаксиса и не входят в ответ. Параметры в угловых скобках замени
фактическими значениями из графа; сами скобки не выводи. Разделяй аргументы одним пробелом, без кавычек. Сохраняй
символы имён буквально: не экранируй `_` и не оформляй аргументы средствами Markdown. Части пути разделяй `/`. Синтаксис
аргументов с пробелами не поддерживается.

### Получить содержимое указанного файла

```
GET-CONTENT <FILEPATH>
```

где:

- `FILEPATH` - путь к файлу в соответствии с путем, указанным в графе
  (части пути через "/" и название файла с расширением)

### Получить структуру из файла

```
GET-STRUCTURE <FILEPATH> <STRUCTURE-TYPE> <STRUCTURE-PATH>
```

где:

- `FILEPATH` - путь к файлу в соответствии с путем, указанным в графе
  (части пути через "/" и название файла с расширением)
- `STRUCTURE-TYPE` - тип структуры (`CLASS`, `FUNCTION`, `METHOD`, `CONSTANT`)
- `STRUCTURE-PATH` - путь структуры.
  При разных типах:
  `CLASS` - название класса (пример: `AccountData`),
  `FUNCTION` - название функции (пример: `load_config`),
  `METHOD` - название класса и метода (пример: `ProjectService.delete_project`),
  `CONSTANT` - название константы (пример: `ERROR_SCHEMA`)
