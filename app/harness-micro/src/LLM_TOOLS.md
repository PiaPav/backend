# Инструменты исследования исходного кода

## Исходный код

| Инструмент | Описание |
|---|---|
| `GET-CONTENT <FILEPATH>` | Получить полное содержимое файла. |
| `GET-STRUCTURE <FILEPATH> <STRUCTURE-TYPE> <STRUCTURE-PATH>` | Получить исходный код указанного класса, функции или метода. |
| `GET-CODE-RANGE <FILEPATH> <START-LINE> <END-LINE>` | Получить заданный включительный диапазон строк файла вместе с номерами строк. |

## Граф проекта

| Инструмент | Описание |
|---|---|
| `GET-GRAPH <PROFILE-ID>` | Получить выбранный вариант графа проекта. |
| `FIND-GRAPH-NODES <QUERY> [KIND] [PATH] [LIMIT]` | Найти объекты в `canonical.full` по имени с необязательной фильтрацией по виду и файлу. |
| `GET-GRAPH-NODE <NODE-ID>` | Получить подробные сведения об объекте из `canonical.full`. |
| `GET-GRAPH-SUBGRAPH <PROFILE-ID> <NODE-ID> <DEPTH> [RELATION-TYPE] [DIRECTION]` | Получить ограниченный подграф вокруг объекта. `DIRECTION` принимает `incoming`, `outgoing` или `both`. |
| `GET-GRAPH-REFERENCES <OWNER-NODE-ID> [REFERENCE-TYPE] [STATUS]` | Получить ссылки, принадлежащие объекту, включая однозначные, неоднозначные и неразрешённые случаи. |

## Показатели

| Инструмент | Описание |
|---|---|
| `GET-METRICS <PROFILE-ID>` | Получить выбранный набор рассчитанных показателей проекта. |
| `GET-METRICS-ITEM <PROFILE-ID> <METRIC-PATH>` | Получить отдельный показатель или раздел выбранного профиля. `METRIC-PATH` задаётся как JSON Pointer. |

## Общие правила

- Профиль выбирается по точному `PROFILE-ID` из
  `GRAPH_AND_METRICS_PROFILES.md`; алиасы и версии профилей не используются.
- Для неизвестного профиля, объекта, пути или значения аргумента инструмент
  возвращает структурированную ошибку, а не пустой результат.
- Ответ сохраняет канонические идентификаторы объектов и сообщает профиль,
  из которого получены данные.
- Ответ явно содержит признаки обрезки и неполноты, а также количество
  найденных и возвращённых элементов.
- Предположительные, неоднозначные и неразрешённые связи не выдаются за
  достоверные.
- `DEPTH`, `LIMIT`, размер диапазона исходного кода и общий размер ответа
  ограничиваются настройками харнесса.
