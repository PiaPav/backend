# Инструменты исследования исходного кода

## Исходный код

| Инструмент | Описание |
|---|---|
| `GET-CONTENT <FILEPATH>` | Получить полное содержимое файла. |
| `GET-STRUCTURE <FILEPATH> <STRUCTURE-TYPE> <STRUCTURE-PATH>` | Получить исходный код указанного класса, функции или метода. |
| `GET-CODE-RANGE <FILEPATH> <START-LINE> <END-LINE>` | Получить заданный диапазон строк файла. |

## Граф проекта

| Инструмент | Описание |
|---|---|
| `GET-GRAPH <PROFILE-ID>` | Получить выбранный вариант графа проекта. |
| `FIND-GRAPH-NODES <QUERY> [KIND] [PATH]` | Найти объекты по имени с необязательной фильтрацией по виду и файлу. |
| `GET-GRAPH-NODE <NODE-ID>` | Получить подробные сведения об объекте графа. |
| `GET-GRAPH-SUBGRAPH <PROFILE-ID> <NODE-ID> <DEPTH> [RELATION-TYPE]` | Получить связи и соседние объекты вокруг указанного объекта с возможностью выбрать вид связи. |
| `GET-GRAPH-REFERENCES <NODE-ID> <REFERENCE-TYPE>` | Получить подробности ссылок на объект, включая неоднозначные и неразрешённые случаи, если они имеются. |

## Показатели

| Инструмент | Описание |
|---|---|
| `GET-METRICS <PROFILE-ID>` | Получить выбранный набор рассчитанных показателей проекта. |
| `GET-METRICS-ITEM <METRIC-PATH>` | Получить отдельный показатель или раздел показателей. |

**Общие требования:** сохранять идентификаторы объектов; отмечать обрезанные ответы и неполные данные; не выдавать предположительные связи за достоверные.
